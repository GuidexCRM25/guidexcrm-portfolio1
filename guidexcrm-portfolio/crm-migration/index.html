The honest bit

This is a portfolio sample, not a case study with a named client. Solara Diagnostics, its territories and every physician, phone number and referral count above are invented — built to show, honestly and interactively, what a real referral-list cleanup looks like: format problems, duplicate sources, and the judgment calls in between. The underlying pattern (mixed phone/fax fields, inconsistent name casing, duplicate contacts arriving from more than one source, missing identifiers) is drawn from real physician-referral CRM work — the fictional data is what's safe to publish.

Part of a three-piece sample set: this migration, a multi-industry CRM build, and a client onboarding portal.
